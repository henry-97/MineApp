# Mine App 4.0.5（多通道版）

> 本版是 `com.henry.appmanager.multi`，可与标准版共存。

## 通知栏文案精简

通知标题在部分机型上放不下，末尾的 `℃` 会被省略号吃掉（显示成 `… · 34…`）。

试过缩小字号，但字符间距不跟着缩，看着反而更松、更不舒服，所以改成直接缩短文案：

| | 原来 | 现在 |
|---|---|---|
| 标题 | `Mine App · 电池 良好 · 健康97% · 34℃` | `Mine App · 电池健康 97% · 34℃` |
| 正文 | `内存 3.2/5.3G (60.6%)　归档 3 · 限制 0` | `内存 61%　归档 3 · 限制 0` |

字号保持系统默认，字距正常。真机实测标题和正文都能完整显示。
