# Mine App 4.4（多通道版）

> 本版是 `com.henry.appmanager.multi`，可与标准版共存。

## 为「合并发布」做准备（本版仍是旧格式）

现在每个版本会发两个 Release（标准版 `v4.x`、多通道版 `multi-v4.x`），在 GitHub 的 Releases 列表里两个 Release 被分成两块，**多通道版容易沉到下面找不到**。

以后打算改成**一个 Release 挂两个 APK**，用户只看一个页面就能选。

但直接切会有断档：已装的旧版只会找自己那个 tag 前缀（多通道版只认 `multi-v*`），切过去就再也收不到更新。所以这一版先做桥接 ——

- **发布仍用旧格式**：`v4.4` + `multi-v4.4` 两个 Release，保证 4.3 及更早的多通道版用户能检测到本版
- **代码已能识别新格式**：本版的多通道版在找不到 `multi-v*` 的 Release 时，会回落到「带 `-multi.apk` 资产的 `v*`」，并继续挑里面的多通道包

这样 4.3 用户能升到 4.4，4.4 用户以后也能升到只发单 Release 的版本，链条不断。

> 本版的更新检查行为与之前完全一致，你不需要做任何操作。
