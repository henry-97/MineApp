# Mine App 4.0.1（标准版）

> 本版是标准版 `com.henry.appmanager`，只走 ADB。
> 执行通道、Shizuku / Root 相关的改动只在多通道版
> （`com.henry.appmanager.multi`）里，请看那个版本的说明。

## 深色模式的状态栏

以前把主题切成深色后，页面是黑的，顶上那条状态栏还是白的 —— 只改了图标颜色，没改底色。

现在底色和图标一起跟着主题走：深色下是深底白字，浅色下是浅底黑字，切换即时生效。

## 设置页

- **按钮尺寸统一**：全部 15px 字号、28px 高。原来「开始 / 检查」是 13px、
  「跟随系统 / 中文」是 15px，并排时一眼能看出不齐
- **说明文字统一 11.5px**：原来同一屏里混着 11 / 11.5 / 12 三种字号
- **「跟随系统」改成「自动」**：省一半宽度，主题和语言都改了

`app-manager.apk`（包名 `com.henry.appmanager`）。
