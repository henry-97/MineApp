# Mine App 4.0.7（多通道版）

> 本版是 `com.henry.appmanager.multi`，可与标准版共存。

## 通知正文补回分隔符

通知第二行原本是：

```
内存 58%　归档 3 · 限制 0
```

`内存` 和 `归档` 之间用的是**全角空格**，视觉上就是一段空白，看着像两个字段黏在一起、少了分隔符。

改成 `·` 之后：

```
内存 58% · 归档 3 · 限制 0
```

真机实测（Shizuku 通道）整行仍能完整显示，没有因为多两个字符被截断。

## 版本

4.0.7（versionCode 207）。
