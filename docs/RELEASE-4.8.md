# Mine App 4.8 · 双版本更新

> 一个 Release 挂两个 APK，按**包名**选你要的那个：
> `MineApp-4.8.apk`（经典版） / `MineApp-4.8-multi.apk`（多通道版）。

## 双版本共同改动

### 新增「操作历史」

以前归档、限制完，过几天就忘了动过哪个应用，只能靠翻状态猜。现在每次操作都会记下来。

**入口**：设置页右上角、`×` 左边新增一个时钟图标。

**弹窗里能看到**：

- 每条记录包含**应用名、包名、操作名**（归档 / 还原 / 限制 / 解限）、时间
- 按时间倒序，最近的排最前
- 顶部可设「保存条数」，默认 200

**保存条数规则**：

| 输入值 | 行为 |
|---|---|
| 1 ~ 10000 | 只保留最近这么多条，**改小时会立刻裁掉较远的记录** |
| **0** | **关闭记录**：不再新增，已有记录保留（不清空） |

清空全部记录需要点标题旁的「清空」，会先弹确认框，确认后才清。

### 设置页样式微调

- Shizuku 授权按钮改为右对齐，与「初始化应用查找功能」那行的「开始」按钮右边缘对齐
- 删掉挤占空间的「先启动 Shizuku 再点授权」说明（真没启动时点授权本来就会提示）

## 经典版（`com.henry.appmanager`）

**本版无专属改动。**

## 多通道版（`com.henry.appmanager.multi`）

**本版无专属改动**，Root / Shizuku / ADB 三条通道都支持记录操作历史。
