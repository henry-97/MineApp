# Mine App 4.0.3（标准版）

> 本版是标准版 `com.henry.appmanager`，只走 ADB。

## 修复：按钮文字粗细不一致

设置页里同一排按钮，有的粗有的细：

- 「主题 / 语言 / 应用名称」这些分段按钮原本是 **400** 字重，只有选中那一个是 **500**
- 「开始 / 检查 / 授权」这类按钮继承的是全局按钮的 **500**

于是「自动」看着比「浅色」细，而「开始」又比两个都粗，同一屏里三种观感。

现在所有按钮统一 **500**，选中态只靠绿色背景区分，不再靠字重。
