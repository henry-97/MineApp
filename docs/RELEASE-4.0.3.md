# Mine App 4.0.3（多通道版）

> 本版是 `com.henry.appmanager.multi`，可与标准版共存。

## 修复：按钮文字粗细不一致

设置页里同一排按钮，有的粗有的细：

- 「主题 / 语言 / 应用名称」这些分段按钮原本是 **400** 字重，只有选中那一个是 **500**
- 「开始 / 检查 / 授权」以及 **ADB / Shizuku / Root** 通道按钮继承的是全局按钮的 **500**

于是「自动」看着比「浅色」细，而「开始」「Shizuku」又比两个都粗，同一屏里三种观感。

现在所有按钮统一 **500**，选中态只靠绿色背景区分，不再靠字重。

## 版本

4.0.3（versionCode 203）。

## 下载

`app-manager-multi.apk`（包名 `com.henry.appmanager.multi`）。

> 已选的执行通道与 Shizuku 授权也都会保留。
