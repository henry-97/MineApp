# Mine App 4.0.6（多通道版）

> 本版是 `com.henry.appmanager.multi`，可与标准版共存。
> **ADB 通道同样包含本次修改** —— 多通道版的 ADB 通道和标准版走的是同一套实现。

## 未授权时不再「一直转圈没提示」

刚装好、还没在手机上点「允许」时，界面会卡在「刷新中，请稍后」将近一分钟，也不说清在等什么。

三处一起改：

- **等待超时 60 秒 → 20 秒**：弹窗没弹出来时不用干等一分钟
- **顶部提示改为复用「等待授权」**：以前那句 `刷新中，请稍后` 其实是卡在等授权，名字骗人；现在直接复用横幅的文案，一处定义两处用
- **「已设置的归档与限制依然生效」恢复显示**：这句话一直都在，但被条件排除在了 `unauthorized` 状态之外 —— 而「刚装未授权」恰恰就是这个状态，最该看到的人反而看不到

现在未授权时的横幅是完整四行：

```
等待授权
解锁手机，勾选「一律允许使用这台计算机进行调试」再点「允许」
已设置的归档与限制依然生效，待方便时再授权即可
查看操作指引 ›
```

> 多通道版如果已选 Shizuku 通道且授权正常，通常不会看到这个横幅；
> 它主要出现在「ADB 通道 + 授权过期」或「首次安装还没授权」时。
