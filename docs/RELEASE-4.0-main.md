# Mine App 4.0（标准版）

> 本版是标准版 `com.henry.appmanager`，只走 ADB。
> Shizuku / Root 执行通道相关的改动**只在多通道版**
> （`com.henry.appmanager.multi`）里，请看那个版本的说明。

## 设置页图标默认折叠

「应用图标」原来默认铺 3 个，占掉设置页两行。

现在默认全部收起，只留一行标题；点「展开」才铺开 6 个
（方块 / 四叶草 × 墨绿 / 金色 / 黑色），选完再点「折叠」收回。
每次进设置页都是收起状态。
