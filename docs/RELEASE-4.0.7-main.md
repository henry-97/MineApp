# Mine App 4.0.7（标准版）

> 本版是标准版 `com.henry.appmanager`，只走 ADB。

## 通知正文补回分隔符

通知第二行原本是：

```
内存 58%　归档 3 · 限制 0
```

`内存` 和 `归档` 之间用的是**全角空格**，视觉上就是一段空白，看着像两个字段黏在一起、少了分隔符。

改成 `·` 之后：

```
内存 58% · 归档 3 · 限制 0
```

真机实测整行仍能完整显示，没有因为多两个字符被截断。
