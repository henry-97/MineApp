# Mine App 4.8.2 · 双版本更新

> 一个 Release 挂两个 APK，按**包名**选你要的那个：
> `MineApp-4.8.2.apk`（经典版） / `MineApp-4.8.2-multi.apk`（多通道版）。

## 双版本共同改动

### 操作历史：「限制」标签改为黄色

历史记录里「限制」的标签原来是蓝色，和应用列表里「已限制」胶囊的琥珀色对不上 —— 同一个概念在两个地方两种颜色。

现在统一取 `#854f0b / #faeeda`（浅色）与 `#fac775 / #3a2a12`（深色），与列表里的「已限制」完全一致。

四种动作的配色现在是这样：

| 动作 | 颜色 |
|---|---|
| 归档 | 红 |
| 还原 | 绿 |
| **限制** | **黄（本次调整）** |
| 解限 | 绿 |
