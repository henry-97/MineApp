# Mine App 4.8.1 · 双版本更新

> 一个 Release 挂两个 APK，按**包名**选你要的那个：
> `MineApp-4.8.1.apk`（经典版） / `MineApp-4.8.1-multi.apk`（多通道版）。

## 双版本共同改动

### 「保存条数」输入框：更短，并加上输入校验

上一版输入框偏宽，说明文字也在单独一行占位置。这一版：

- 输入框收窄，紧挨「保存条数」；说明文字挪到输入框右侧
- 输入**超过 10000** → 自动截断成 `10000`
- 输入**纯数字以外的内容**（含正负号、字母、清空）→ 自动回到默认值 `200`

| 输入 | 结果 |
|---|---|
| `10001` | `10000` |
| `-5` / `+8` / `abc` / 留空 | `200` |
| `0` | `0`（关闭记录，纯数字所以允许） |
| `150` | `150` |

顺带把输入框类型从 `number` 换成 `text + inputmode="numeric"` —— 原生 number 输入框允许输入 `-` 和 `e`，换成 text 后由脚本统一裁决。
