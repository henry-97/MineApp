# Mine App 4.0.8（标准版）

> 本版是标准版 `com.henry.appmanager`，只走 ADB。

## 授权提示更准确

两处调整：

- **「等待授权」改为「确认授权中」**：横幅标题和顶部提示用的是同一句文案，改一处两边都变
- **顶部提示的触发时间 4 秒 → 10 秒**：正常拉一次应用列表（要采 PSS）也可能超过 4 秒，过早提示「确认授权中」会误报；10 秒基本只会在真的卡在授权弹窗上时才出现

20 秒的授权等待超时不变，超时后仍显示完整的「确认授权中」横幅（含解锁手机、勾选「一律允许」的操作指引，以及「已设置的归档与限制依然生效」）。

## 版本

4.0.8（versionCode 208）。
