# Mine App 4.5（标准版）

> 本版是标准版 `com.henry.appmanager`，只走 ADB。

## 修复 4.4 的更新检查缺陷

4.4 在挑选 Release 时只看「有没有对应的 tag」，没看「这个版本是不是比当前新」。

结果：只要历史上存在过 `multi-v4.4`，多通道版就会一直停在那里，永远看不到之后发布的版本 —— 相当于把更新通道堵死了。

4.5 加了版本过滤：**只有比当前版本新的 Release 才算数**，否则继续往下找。

## 为「合并发布」做准备（本版仍用旧格式）

现在每个版本会发两个 Release（`v4.x` 和 `multi-v4.x`），在 Releases 列表里被分成两块，多通道版容易沉到下面找不到。以后打算改成一个 Release 挂两个 APK。

切换格式会有断档风险：已装的旧版只会找自己那个 tag 前缀。所以 **4.5 作为桥接版**——

- **发布仍用旧格式**：`v4.5` + `multi-v4.5`，保证 4.4 及更早的用户能检测到本版
- **代码已能识别新格式**：多通道版在「没有更新的 `multi-v*`」时会回落去找「带 `-multi.apk` 资产的 `v*`」

这样一来，下一个版本就可以只发一个 Release 了，链条不会断。

> 本版的更新检查行为与之前一致，你不需要做任何操作。
