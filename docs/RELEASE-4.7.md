# Mine App 4.7 · 双版本更新

> 一个 Release 挂两个 APK，按**包名**选你要的那个：
> `MineApp-4.7.apk`（经典版） / `MineApp-4.7-multi.apk`（多通道版）。

## 双版本共同改动

两个版本都能用到的改动。

### 1. 更新检查逻辑简化

以前是「先找 `multi-v*`，找不到再回落找 `v*`」。这套逻辑已经没用了（4.6 起只发一个 `vX`），而且有个隐患：如果同时存在 `multi-v4.6` 和 `v4.7`，它会先命中较旧的 4.6。

改成两步：

1. 找出**编号最新**的 Release
2. 看这个 Release 里**有没有本通道的 APK**
   - 有 → 提示更新
   - **没有 → 显示「已是最新」**，绝不退回去装旧版本，更不会装成另一个通道的包

举例：如果某一版只发了经典版包，多通道版检查更新时会显示「已是最新」，不会提示下载，也不会把经典版包装进来。

### 2. Shizuku 授权按钮右对齐

上一版删掉挤占空间的说明文字后，按钮不再顶到边界，但位置还跟着状态文字走，和下面「初始化应用查找功能」那行的「开始」按钮没对齐。

这一版把授权按钮推到行末，两行按钮右边缘对齐：

```
初始化应用查找功能                    [开始]
Shizuku 授权        未授权           [授权]
```

## 经典版（`com.henry.appmanager`）

## 多通道版（`com.henry.appmanager.multi`）

**本版无专属改动**，多出的 Root / Shizuku 通道与之前一致。
