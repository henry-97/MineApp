# Mine App 4.2（多通道版）

> 本版是 `com.henry.appmanager.multi`，可与标准版共存。

## 「检查更新」不再被刷新列表堵住

以前「检查更新」和「刷新列表」共用一个单线程队列。列表刷新要采内存、跑十几条系统命令，一跑几十秒；这期间点「检查」，请求只能排在后面干等，界面看着像卡死。

而检查更新只是上网查一下版本号，**完全不碰手机系统**（ADB 通道和 Shizuku 通道都一样），没必要跟那些活儿挤一条队。现在给它独立线程池，两者互不影响。

顺带把 HTTP 超时从 8 秒放宽到 15 秒（GitHub 走代理偶尔慢），并在代码里注明：**排队等待时间不计入这个超时**，它只在真正连接/读取时计时。
