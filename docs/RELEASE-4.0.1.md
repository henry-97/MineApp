# Mine App 4.0.1

> 主要是设置页的观感调整，外加两处实际修好才敢说「沉浸」的改动。

---

## 一、深色模式的状态栏终于也是深色了

以前把主题切成深色后，页面是黑的，顶上那条状态栏还是白的 —— 只改了图标颜色，没改底色。

现在底色和图标一起跟着主题走：深色下是深底白字，浅色下是浅底黑字，切换即时生效。

## 二、设置页更紧凑、更整齐

- **按钮尺寸统一**：全部 15px 字号、28px 高。原来「开始/检查」是 13px、「跟随系统/中文」是 15px，并排时一眼能看出不齐
- **说明文字统一 11.5px**：原来同一屏里混着 11 / 11.5 / 12 三种字号
- **「跟随系统」改成「自动」**：省一半宽度，主题和语言都改了
- **执行通道、Shizuku 授权的说明并到同一行右端**，不再各占一整行
- 通道按钮顺序调整为 **ADB / Shizuku / Root**，选中态由黑色改为绿色

## 三、执行通道改为「首次安装自动判断」

去掉语义含糊的「自动」选项，改成装好第一次打开时判断一次：

| 设备情况 | 自动选 |
|---|---|
| Shizuku 服务在跑 | Shizuku |
| 有 root（检测到 su） | Root |
| 两者都没有 | ADB |

判断**只有这一次**：之后你手动选的通道、覆盖安装、重启，都不会被改掉。只有卸载重装才会重新判断。

## 四、Root 通道变成真正独立的通道

以前选 Root 只影响「建索引时给 launcher.db 提一次权」，其余命令仍然走 ADB —— 没连 `adb tcpip 5555` 的话，选了 Root 也什么都干不了。

现在 Root 通道下所有命令都走本机 `su`，和 Shizuku 一样不依赖 ADB。

## 五、设置页不再「空白一阵」

之前打开设置页，「执行通道」和「Shizuku 授权」两行有时要等好几秒才出现。原因是这两个查询和「刷新列表」挤在同一个单线程里排队。现在它们独立响应，打开即显示。

## 下载哪个

| 文件 | 包名 | 说明 |
|---|---|---|
| `app-manager.apk` | `com.henry.appmanager` | 标准版，只走 ADB |
| `app-manager-multi.apk` | `com.henry.appmanager.multi` | 多通道版，多出 Root / Shizuku 通道 |

两个包名不同，可以同时安装，更新通道互不干扰。

> **升级提示**：覆盖安装不会丢已有的归档与限制，也不会丢 adb 授权。
> 4.0 里存的「自动」通道会按 ADB 处理，想用 Shizuku / Root 在设置里选一次即可。
