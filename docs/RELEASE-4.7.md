# Mine App 4.7

> 两个版本合在一个 Release 里发布，按包名选你要的那个。

## Shizuku 授权按钮右对齐

上一版删掉挤占空间的说明文字后，按钮不再顶到边界，但位置还是跟着状态文字走，和下面「初始化应用查找功能」那行的「开始」按钮没对齐。

这一版把授权按钮推到行末，两行的按钮右边缘现在对齐了：

```
初始化应用查找功能                    [开始]
Shizuku 授权        未授权           [授权]
```

## 更新检查逻辑简化

以前是「先找 `multi-v*`，找不到再回落找 `v*`」，这套逻辑现在没用了（4.6 起只发一个 `vX`），而且有个隐患：如果同时存在 `multi-v4.6` 和 `v4.7`，它会先命中较旧的 4.6。

改成两步：

1. **找出编号最新的 Release**
2. **看这个 Release 里有没有本通道的 APK**
   - 有 → 提示更新
   - **没有 → 显示「已是最新」，绝不退回去装旧版本，更不会装成另一个通道的包**

举例：如果某一版只发了标准版包，多通道版检查更新时会显示「已是最新」，不会提示你下载，也不会把标准版包装进来。
