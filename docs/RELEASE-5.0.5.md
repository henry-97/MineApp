## Mine App 5.0.5 · 双版本更新

### 双版本共同改动

**打开 App 刷新列表时，先补一次墓碑再拉数据**

之前墓碑补做只挂在后台的「全量刷新」上（亮屏 3 分钟 / 熄屏 30 分钟）。也就是说：用户打开 App、看到某个应用标着「已限制」时，那条限制可能是几分钟前打的，中途被用户打开过、已经失效了。

现在改成 **每次拉全量列表前先补一次**，覆盖三种入口：

| 入口 | 是否补做 |
|---|---|
| 手动点刷新 | ✅ |
| 切回前台自动刷新 | ✅ |
| 首次打开 App | ✅ |

补完再取列表，所以屏幕上显示的「已限制」和实际状态是一致的。

**开销**：只对「已限制且当前有进程」的包执行，实测 1 个包 22ms、40 个包约 2 秒。代价是列表加载会慢一点，换来的是状态可信。

**顺带修了一个边界**：前台拉列表时可能还没跑过后台全量刷新，限制名单缓存是空的。现在遇到空名单会现查一次（约 0.5 秒），不会因为「没缓存」就跳过补做。
