# Mine App 4.0（多通道版）

> 本说明适用于多通道版 `com.henry.appmanager.multi`。
> 标准版请看 `RELEASE-4.0-main.md` —— 它没有执行通道 / Shizuku / Root。

> 这一版解决一个反馈较多的问题：Shizuku 明明授权了，界面还是显示「调试未连接」。

---

## 一、修掉「授权了仍显示未连接」（多通道版）

**问题**：手机上 Shizuku 已经点了「始终允许」，App 设置页也显示「已授权」，
但主界面右上角一直挂「调试未连接」，还提示去电脑上执行 `adb tcpip 5555`。

**根因**：执行通道选的是「自动」（默认值），而旧代码只在**显式选 Shizuku** 时才启用它。
选「自动」等于只等 ADB —— 授权白给了，那条 Shizuku 分支永远进不去。

**现在**：「自动」= 能用就用。Shizuku 已授权就走 Shizuku；没授权会自动回落到 ADB，
不会误判。想在两者之间强制指定，仍然可以手动选 Shizuku / ADB / Root。

## 二、切换通道后立即生效

以前在设置里换执行通道，主界面状态不会重判，必须杀掉进程重启才会变。
现在切完立刻重新检测，不用重启。

## 三、设置页图标默认折叠

「应用图标」原来默认铺 3 个，占掉设置页两行。现在默认全部收起，
只留一行标题；点「展开」才铺开 6 个（方块/四叶草 × 墨绿/金色/黑色），
选完再点「折叠」收回。每次进设置页都是收起状态。

## 四、其他

- 顺带修了个隐性卡顿：「自动」通道下没有装 Shizuku 的用户，每次刷新原本要多等 1.5 秒
- 版本号 4.0（versionCode 200）
